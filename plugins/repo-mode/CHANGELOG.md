# Changelog

All notable changes to **repo-mode**. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed
- README diagrams now show the optional `researcher` and `planner` (dashed cards) and Round 1b of the wizard. Files renamed to `-v5` to bypass GitHub's image cache.

## [1.8.0] - 2026-11-12

### Added
- Optional **`researcher`** subagent: reads web pages and documentation and returns a short answer with source URLs and exact supporting lines. Tools `WebFetch, WebSearch` only (no file access, no Bash, no edits), Haiku by default, treats web pages as data and keeps repository details out of search queries. WebFetch already condenses each page, so the saving is the search-and-fetch round trips, not hidden raw pages.
- Optional **`planner`** subagent: read-only planning before a change that touches several files (files, order, risks, how to verify). Opus by default; setup recommends skipping it when the main model is already Opus, `opusplan` or Fable. Named `planner`, so the built-in `Plan` agent is left alone.
- Setup: new Round 1b with one question per agent (model or skip); two matching lines in the delegation rules block.

### Notes
- Neither agent has been measured. They follow the delegation rule of thumb (long output or a different model tier, not splitting for its own sake); `/usage` shows what they cost.
- `/repo-mode:status` no longer flags a managed `planner` on Opus as an expensive subagent.

## [1.7.0] - 2026-11-11

### Fixed
- **Re-running `/repo-mode:setup` no longer breaks `/repo-mode:off`.** A second run used to record repo-mode's own values as the "previous" ones and lose the created-by flags. A re-run now keeps the original previous values, removes what is no longer chosen (agents, hooks, deny rules, rules block) and lists those removals in the plan.
- The test-output filter also runs inside subagents, so `test-runner` saw shortened output while being asked for verbatim failures. `test-runner` and `escalate` now read the saved full-output file.
- The filter dropped failure details in the middle of long `cargo test` output and could do so for PHPUnit: `panicked` and `Failed asserting` are now part of the failure pattern (both the Bash and the PowerShell script).
- Git worktrees: the exclude file's path now comes from `git rev-parse --git-path info/exclude` instead of a hard-coded `.git/info/exclude`.
- Reference: `fable` resolves to Fable 5.2; the advisor pairing table matches the current docs (Fable 5.2 main accepts only a Fable 5.2 advisor); `best` is the same model as `opus`.

### Changed
- Setup's report and `/repo-mode:status` now warn that `/model <name>` saves the model globally, like the `/advisor` picker.
- `/repo-mode:status` mentions that subagents inherit the advisor.
- README: new section explaining why Sonnet is the recommended main model and where Fable fits.
- `off`, `status` and `handoff` answer in the user's language, with no Greek default; `off` also finds a leftover PowerShell hook script; `test-runner` looks in CLAUDE.md for the test command.
- README diagrams are now hand-drawn SVGs (`docs/*.svg`, generated by `docs/build_diagrams.py`) instead of Mermaid: blueprint style, each model name in its own color with a rank marker, no cropped or overlapping labels, the same look on light and dark GitHub themes, English and Greek versions.

## [1.6.0] - 2026-11-11

### Added
- **`/repo-mode:handoff`**: writes `HANDOFF.md` (goal, state, next steps, decisions, commands, risks) so the next session can start fresh instead of resuming a long conversation, which re-reads the whole history uncached. It writes only that file and never commits it.
- Optional **secrets Read deny rules** in setup (`.env` files, `~/.ssh`, `secrets/`): a safety option, not a cost one. They stop Claude's file tools and recognized file commands such as `cat`, not scripts that open files themselves.

## [1.5.0] - 2026-11-11

### Added
- Optional **`escalate` subagent** (read-only, `fable` or `opus`, effort high) for problems the advisor and two of the main session's own attempts could not solve, plus a delegation rule that says when to call it. The advisor takes only one model, so this is the closest to "Opus advisor, Fable when it's really hard". The main session decides whether to call it.
- Setup: `escalate` in the subagents question; a model question (Fable or Opus) in Round 4.

## [1.4.0] - 2026-11-10

### Added
- **PowerShell variant of the test-output filter** (`.claude/hooks/repo-mode-filter-tests.ps1`) for the separate PowerShell tool: same rules as the Bash one (plain test commands only, ≤ 60 lines shown in full, otherwise failure context + last 20 lines, real exit code kept, full output saved to a temp file). Works with PowerShell 7 and Windows PowerShell 5.1; no `jq` needed. The setup question now offers Bash, PowerShell, both, or none.
- Setup registers the PowerShell hook with `"shell": "powershell"` on native Windows and with `pwsh -NoProfile -File` elsewhere; `/repo-mode:off` and `/repo-mode:status` handle both variants.

### Changed
- The setup wizard now always talks in English.

## [1.3.0] - 2026-11-09

### Added
- Optional **test-output filter**: a PreToolUse hook (`.claude/hooks/repo-mode-filter-tests.sh`) that rewrites plain test commands (`pytest`, `npm test`, `go test`, `cargo test`, `dotnet test`, …). Claude sees the full output when it is 60 lines or less; otherwise the failure context (up to 100 lines) and the last 20 lines. The real exit code is kept, and the full output is saved to a temp file. Commands with shell operators pass through unchanged; without `jq` the hook does nothing.
- Setup preflight checks for `bash` and `jq`; new "Test output" question in Round 4.
- `/repo-mode:off` removes the hook entry and script; `/repo-mode:status` reports them.

## [1.2.0] - 2026-11-08

### Added
- "Workflows" question: per-repo `workflowSizeGuideline` (default / `small` / `large` / `unrestricted`).
- Optional delegation rule: stop a fix-and-retest loop after two rounds without progress.
- English README (`README.en.md`); Greek stays the default `README.md`.
- Installation section moved to the top of the README, with update, uninstall and migration steps.

### Changed
- `CLAUDE_CODE_SUBAGENT_MODEL` is documented as also covering dynamic-workflow agents.
- `/repo-mode:status` flags `ultracode: true`; ultracode is never written by setup.

## [1.1.0] - 2026-11-08

### Added
- `effort` per agent: `low` for Explore and test-runner, `high` for audit.
- `autoCompactWindow: 100000` for a Haiku Explore agent (Haiku 5.5 price tier above 100K-token prompts).
- "Other agents" question: default model for general-purpose, Plan and other subagents via `env.CLAUDE_CODE_SUBAGENT_MODEL`.
- Main-session effort question (`effortLevel`) and `opusplan` as a main-model option.
- Delegation rule asking for return format and evidence.
- README with a benefits table, diagrams and sources.

### Changed
- Advisor pairing table updated: Haiku 5.5 as main model with an advisor is supported.
- Delegation threshold: 10+ files or 3+ independent pieces (was more than ~5 files).
- Agent descriptions name their trigger and say "use proactively"; audit asks for evidence and skips style.

## [1.0.0] - 2026-11-08

### Added
- `/repo-mode:setup` wizard: main model, advisor, helper subagents (Explore, test-runner, audit), scope, delegation rules, Read deny rules, code-intelligence plugin. Writes nothing until the plan is approved.
- `/repo-mode:status` (read-only report) and `/repo-mode:off` (exact undo from `.claude/repo-mode.json`).
- Personal scope hides all files via `.git/info/exclude`.
