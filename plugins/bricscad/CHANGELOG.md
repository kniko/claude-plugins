## [1.0.0] - 2026-11-08

### Added
- MCP server `bricscad` (run with `uv`): status, open/save, LISP and command line, entities/solids/layers/extents queries, delete, zoom, screenshot, plot to PDF, DXF export, `export_geometry` with a Blender importer.
- Skill `bricscad`: plans, sections, elevations and 3D solids with Greek text, measured dimensions and hatches; Python generators that write ASCII LISP; known pitfalls.
